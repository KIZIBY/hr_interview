# DESIGN.md — визуальный контракт микро-платформы интервью

Относится к: `interviewer.html`, `candidate.html`, `guide.html` (см. `PRD.md`).

## 1. Источник истины

Дизайн-система — **X5 Group Design System** из этого репозитория: `X5_Group_Design_System/README.md` (канон правил, при конфликте выигрывает он) + `X5_Group_Design_System/SKILL.md`. Все токены — из `X5_Group_Design_System/colors_and_type.css`; этот файл **импортируется первым** на каждой странице:

```html
<link rel="stylesheet" href="X5_Group_Design_System/colors_and_type.css">
```

Hex-значения в коде страниц не хардкодятся — только CSS-переменные. Шрифты — из `X5_Group_Design_System/fonts/` (подключены через `@font-face` в том же CSS), логотипы — из `X5_Group_Design_System/assets/logos/`. Образцы вёрстки — `X5_Group_Design_System/slides/` и `preview/*.html`.

## 2. Маппинг токенов на роли продукта

| Роль в продукте | Токен |
|---|---|
| Фон страницы | `--x5-surface` |
| Панель/карточка (сайдбар, детали, лист оценки) | `--x5-surface` + hairline `--x5-divider`, радиус `--radius-card` |
| Подложка кода (примеры, эталоны, редактор) | `--x5-surface-soft` / редактор — `--x5-surface-alt`, `--font-mono`, радиус `--radius-sm` |
| Выбранная строка списка | заливка `--x5-surface-alt` (не бордер) |
| Основной текст | `--x5-ink` |
| Второстепенный текст (подписи, метки времени) | `--x5-ink-muted`; третичный — `--x5-ink-quiet` только на белом |
| Основное действие («Показать кандидату», «Старт», «Зафиксировать») | пилл по паттерну `.x5-badge`: заливка `--x5-ink`, текст `--x5-white`, радиус `--radius-pill` |
| Второстепенное действие («Сброс», «Изменить») | `.x5-badge--light`: белый фон, рамка `--x5-divider`, текст `--x5-ink` |
| Success / «берём» / GO / «кандидат подключён» | `--x5-success` |
| Ошибка / стоп / NO-GO / overtime | `--x5-danger` |
| Предупреждение («требует авторинга», лимит синка) | `--x5-warn` |
| Активный сегмент таймбокса | `--x5-citrus-soft`; пройденный — `--x5-surface-soft` |
| Разделители | `--x5-divider`; ячейки таблиц и поля форм — `--x5-divider-strong` |
| Радиусы | чипы/код `--radius-sm` (8), карточки `--radius-card` (16), пиллы `--radius-pill` (999); крупнее 16 не использовать |
| Тени | по умолчанию плоско; sticky-панели — `--shadow-card`; glow и inner shadow запрещены |
| Фокус | ring 2px solid `--x5-ink`, offset 2px; на тёмных заливках — `--x5-white` |
| Моушен | `--dur-fast` 120 / `--dur-base` 200 / `--dur-slow` 320 ms, `--ease-standard` `cubic-bezier(.2,0,0,1)`; ничего дольше 400 ms; `prefers-reduced-motion` обязателен |
| Типографика | заголовки `--fs-h3`/`--fs-h4` Medium; текст `--fs-body`; условие у кандидата `--fs-body-lg`; подписи `--fs-caption` |
| Иконки (если нужны) | Lucide как задокументированная подмена X5-сета — помечать как временную (README §4.2) |

`guide.html` — тот же визуальный язык, но формат длинного справочного документа, а не панели: sticky-оглавление в левой колонке (роль второстепенного текста `--x5-ink-muted`), баннер конфиденциальности на `--x5-citrus-soft`, карточки задач и таблицы по маппингу выше. Печатный режим (`@media print`) прячет хром (topbar, TOC, логотип), сохраняет плашку конфиденциальности и выносит секцию «Оценка и вердикт» на отдельный лист A4 как печатный оценочный лист.

## 3. Жёсткие правила X5 — не нарушать

- Шрифт только **X5 Sans Regular / Medium** — никаких Bold, Light и системных подмен.
- Основной текст — **`--x5-ink` (#303145)**, не бренд-зелёный.
- Логотип — **снизу слева, 0° поворота**, никогда не перекрашивать; отступ — `--slide-margin`.
- **Без эмодзи в хроме интерфейса**, без восклицательных знаков, без повелительных заголовков. Маркеры 🟢/🔴 допустимы только внутри данных сигналов из банка задач (контент интервью) и дублируются текстом для скринридеров.
- **Sentence case** во всех заголовках и кнопках; **длинное тире `—`** как системный разделитель; без висячих предлогов.
- Тон текста — русский, деловой, сдержанный; английские техтермины (`system design`, `follow-up`) не транслитерируются.

## 4. Anti-slop — запрещено

- Дефолтные фиолетовые/indigo-градиенты и любые «AI-дефолтные» палитры; фон — белый.
- Cookie-cutter SaaS-лейаут: три одинаковые карточки с иконками, hero-блоки, маркетинговые бейджи.
- **Цветной левый бордер у карточек** — X5 использует заливки, бейджи и hairline-рамки, не акцентные полосы.
- Кремовые фоны, serif-шрифты, терракотовые акценты (дефолтная эстетика модели — здесь неуместна).
- Bounce, spring, parallax, скелетоны-переливы «радугой»; только спокойные fade/цветовые переходы на токенах моушена.
- Тёмная тема, стеклянный blur-морфизм, неоновые тени.
- Эмодзи как иконки интерфейса, декоративные иллюстрации «из стока».
