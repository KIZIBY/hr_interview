# Интервью FDE — платформа и хендбуки технического собеседования

Материалы для проведения собеседований на позицию **Forward Deployed Engineer (Middle+)**:
браузерная платформа для живого технического интервью (этап 2 из 3) и хендбуки интервьюера.
Всё — статические HTML-страницы: без бэкенда, без сборки, без зависимостей.

## Что здесь есть

Процесс найма состоит из трёх этапов: HR-скрининг → **техническое интервью** → финал с лидом
команды. Этот репозиторий обслуживает технический этап (и хранит хендбук финального).

Технический этап — 60 минут: разговор, немного живого кода и мини-дизайн. Проверяется
инженерный фундамент под AI-инструментами по пяти зонам (CS-фундамент, system design,
проектирование агентов, прод-зрелость, AI-практика). Главный риск, от которого защищает
методология, — нанять «вайбкодера»: человека, который собрал агента через AI-ассистента,
но не понимает, что у него под капотом.

## Быстрый старт

Нужен только Python (есть в macOS/Linux из коробки) и браузер.

```bash
git clone https://github.com/KIZIBY/hr_interview.git
cd hr_interview
python3 -m http.server 8000
```

Откройте <http://localhost:8000> — увидите навигацию по всем страницам.

> Сервер обязателен для платформы: страницы загружают банк задач через fetch
> и синхронизируются между вкладками — при открытии как file:// это не работает.
> Хендбуки (`handbooks/`) самодостаточны и открываются двойным кликом.

## Как проводить интервью

1. **Подготовка (за 15 минут до).** Прочитайте гайд — `platform/guide.html`: флоу этапа,
   пять зон, маркеры сильных и слабых ответов. Держите его в отдельном окне браузера,
   не в том, которое будете демонстрировать.
2. **Старт.** Откройте `platform/interviewer.html` (пульт) и `platform/candidate.html`
   двумя вкладками одного браузера. Бейдж в шапке пульта покажет «кандидат подключён».
   Вкладку кандидата выведите на второй экран или шарьте только её.
3. **Интервью.** На пульте: банк из 13 задач с фильтрами — клик по задаче сразу показывает
   её кандидату; таймер с подсветкой текущего сегмента (6 таймбоксов на 60 минут);
   код кандидата зеркалится в реальном времени с меткой свежести. Подсказки по ходу —
   в гайде: у каждой задачи есть ссылка «памятка по задаче».
4. **Оценка.** Кнопка «Оценка» на пульте: пять критериев по шкале 1–4, вердикт GO/NO-GO
   считается сам (средневзвешенное ≥ 3.0 и без «1» в стоп-строках). Зафиксируйте
   в течение 10 минут после интервью.
5. **Сброс.** Кнопка «Сброс» готовит платформу к следующему кандидату: чистит таймер,
   задачи, зеркало, черновики и оценки.

Кандидат видит **только** свою страницу: эталонные решения и критерии оценки на неё
физически не попадают. Но `tasks.json` с эталонами технически доступен любому, кто знает
адрес сервера, — поэтому платформа рассчитана на одну машину интервьюера, а репозиторий
приватный.

```

├── platform/                   Платформа интервью (этап 2)
│   ├── interviewer.html/.js    Пульт интервьюера: банк задач, таймер, зеркало, оценка
│   ├── candidate.html/.js      Страница кандидата: условие и редактор кода
│   ├── guide.html              Гайд интервьюера: флоу, зоны, памятка решений
│   ├── sync.js                 Синхронизация вкладок (BroadcastChannel + localStorage)
│   └── tasks.json              Банк задач — единственный источник условий и эталонов
│
├── handbooks/                  Хендбуки интервьюера (самодостаточные HTML-файлы)
│   ├── interview-stage-2-handbook.html   Этап 02: техническое (решения задач встроены)
│   └── interview-stage-3-handbook.html   Этап 03: финал с лидом команды
│
├── X5_Group_Design_System/     Дизайн-система X5: токены, шрифты, логотипы
├── sources/                    Исходные материалы (.docx: вакансия, сценарий этапа, задачи)
│
├── docs/                       Документация процесса и QA-отчёты (docs/qa/ — тесты)
├── specs/                      Спецификации фич (пайплайн разработки)
├── CLAUDE.md · PRD.md · DESIGN.md   Документы для AI-агентов и продуктовые
├── Product_agents/ · scripts/ · tests/ · .claude/ · team.params
│                               Фреймворк AI-агентов, на котором разрабатывается репозиторий
```

## Как это устроено

- **Синхронизация вкладок** — `platform/sync.js`: шина BroadcastChannel (fallback —
  localStorage) между пультом и страницей кандидата на одном origin. Пульт держит
  состояние сессии, кандидат — проекция; heartbeat каждые 3 секунды поддерживает
  бейдж живости, снапшот в localStorage переживает перезагрузку страницы.
- **Банк задач** — `platform/tasks.json`: 13 задач с условиями, примерами, эталонными
  решениями, сигналами «берём/стоп» и follow-up вопросами. Пульт и гайд рендерят его
  напрямую: новая задача в JSON автоматически появляется в обоих. Страница кандидата
  рендерит только «белый список» полей — эталоны в её DOM не попадают.
- **Дублируемые константы** — таймбоксы и критерии оценки живут в `interviewer.js`
  и продублированы в таблицах гайда; гайд сверяет их при загрузке и пишет предупреждение
  в консоль при расхождении (пометки SYNC-CONTRACT в обоих файлах).
- **Хендбук этапа 02** — снапшот: карточки задач с решениями встроены в файл, чтобы его
  можно было переслать одним файлом. После изменения `tasks.json` хендбук нужно пересобрать.

## Тесты

Браузерные e2e-тесты на Playwright (нужен установленный Playwright с Chromium;
сервер на :8000 должен быть запущен):

```bash
node docs/qa/2026-07-12-e2e/e2e-run.mjs        # платформа целиком: 44 проверки
node docs/qa/2026-07-12-e2e/guide-smoke.mjs    # гайд: 15 проверок
node docs/qa/2026-07-12-e2e/point-checks.mjs   # точечные: heartbeat, метка свежести
```

## Как обновлять задачи

Редактируйте `platform/tasks.json` — пульт и гайд подхватят изменения при перезагрузке
страницы. Обязательные поля и форматы задач описаны в PRD.md. После изменения таймбоксов
или критериев оценки в `interviewer.js` обновите таблицы в `guide.html` (см. пометки
SYNC-CONTRACT) и пересоберите хендбук этапа 02.

## Конфиденциальность

Гайд, хендбуки и `tasks.json` содержат эталонные решения. Не передавайте их кандидатам,
не публикуйте репозиторий и не демонстрируйте при шаринге экрана ничего, кроме вкладки
кандидата. Правила гигиены — в баннере гайда и в хендбуке этапа 02.
